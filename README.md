# 🌌 onzeHub - Premium Script Hub

![QuantumHub UI](https://raw.githubusercontent.com/dawid-scripts/Fluent/master/Images/Fluent.png)

onzeHub es un framework de scripts para Roblox diseñado para ofrecer la mejor experiencia visual y funcional. Utiliza la librería **Fluent**, inspirada en el diseño moderno de Windows 11.

## ✨ Características Premium
*   **Interfaz Modernísima**: Efectos de acrílico (transparencia), animaciones suaves y modo oscuro.
*   **Gestor de Configuración**: Guarda tus ajustes de velocidad y salto automáticamente para la próxima vez que juegues.
*   **Detección de Juegos**: Estructura lista para añadir funciones específicas por GameID.
*   **Compatible**: Funciona con los ejecutores más populares (Wave, Solara, Celery, etc.).

## 📂 Cómo expandir el Hub
1.  **Funciones Universales**: Añade nuevos Sliders o Toggles en la sección `Universal` de `src/init.lua`.
2.  **Scripts por Juego**: Puedes usar `game.PlaceId` para condicionar qué botones aparecen según el juego en el que estés.
3.  **Temas**: Puedes cambiar el color principal en la configuración de `Fluent`.

## 🛠️ Instalación rápida
Copia este enlace en tu ejecutor para cargar siempre la versión más reciente:
```lua
loadstring(game:HttpGet("TU_ENLACE_RAW_AQUÍ"))()
```
